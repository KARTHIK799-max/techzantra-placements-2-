# TechZentra – Placements Page

## About the Project
The TechZentra Placements Page is a dedicated website page designed to showcase placement assistance, career preparation, interview guidance, and career opportunities for students.

## Features
- Modern and responsive UI design
- Placement support information
- Resume-building guidance
- Technical interview preparation
- Placement preparation roadmap
- Career opportunities
- Student success stories section
- Frequently Asked Questions (FAQs)

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `placements.html`.
4. Right-click and select **Open with Live Server**.
